# Portfolio

A personal developer portfolio website: a small, deliberately minimal static site that presents the owner's identity and work. It intentionally excludes a blog, CMS, or any content-platform features — it showcases, it does not publish.

## Language

**Portfolio Site**:
The website as a whole — the owner's public professional face on the internet.
_Avoid_: Blog, homepage (when referring to the whole site), personal site

**Project**:
A piece of real, showable software work presented on the site, with a name, short pitch, tech stack, and external link (demo or source).
_Avoid_: Work item, repo, post

**Owner**:
The developer whose portfolio this is. All first-person copy ("I", "my") on the site refers to them.
_Avoid_: User, admin, author
